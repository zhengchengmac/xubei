# 续杯 · 每天自动领 AI 编程工具的免费额度

macOS 菜单栏小工具。每天定时跑一轮，把各家送的活动积分/免费额度领下来，然后在菜单栏告诉你：**今天领到了没、哪家快过期、按现在的速度还能用几天**。

平时不占菜单栏位子——只在**该领的没领到、有失败、或者你正在用某家工具**时才出现。

## 它管这几家

| 家 | 签到领积分 | 读实时余额 |
|---|---|---|
| Qoder CN | 是 | 是（含每笔加油包的到期日） |
| Trae CN | 是 | 是 |
| MiniMax Code | 是 | 是 |
| Kimi | — | 是（套餐到期日） |
| ZCode | — | 是（一次性/周期额度） |
| DeepSeek | — | 是（余额，需自备 API Key） |
| CodeBuddy / 豆包 | — | 读不到，如实显示"读不到" |

读不到的一律如实标出来，不猜、不编。

## 装

```bash
git clone <这个仓库> ~/续杯
cd ~/续杯 && ./install.sh
```

`install.sh` 做四件事：建 Python 虚拟环境并装依赖 → 生成两个 LaunchAgent（定时器 + 菜单栏常驻）→ 编译打包 App 到 `/Applications/续杯.app` → 跑一次冒烟检查。

**第一次从 GitHub 下载打开会被 Gatekeeper 拦**（作者证书签名、未做公证，公证要交 Apple 的年费）。右键点 App →「打开」→「打开」即可，或者：

```bash
xattr -dr com.apple.quarantine /Applications/续杯.app
```

## 用

```bash
./build.sh                      # 改了代码后重新打包
.venv/bin/python 领积分.py       # 手动跑一轮（接口幂等，重复跑只会回"已领过"）
bash tools/冒烟检查.sh           # 只读自检，30 秒给结论
"/Applications/续杯.app/Contents/MacOS/AgentPoints" --dump    # 不开界面看菜单栏该显示什么
```

菜单栏出现时，点开能看到：一句话结论 → 每家一条彩色进度条（绿=送的、蓝=买的、灰=已用，右边是剩余额度和有效期）→ 最近三条活动 → `立即领一次` / `看今天的记录` / `关于` / `退出`。

想让它露出来一会儿：**双击 `/Applications/续杯.app`**，图标会出现一小时。

## 隐私

- 所有请求都是你的机器直连各家官方接口，**本项目不搭任何服务端，不上传任何东西**。
- 凭据全部留在本机，沿用各家桌面客户端已经存在的登录态；本项目**不申请任何系统权限**（不要辅助功能、不要完全磁盘访问、不要通知权限）。
- DeepSeek 需要你自己的 `sk-` API Key，放在 `.deepseek-key`（权限 0600，已在 `.gitignore` 里），代码不读钥匙串。
- 日志和状态文件（`领积分.log`、`今日状态.json`、`积分盘查.json`、`领积分台账.jsonl`）都在项目目录里，含你的账号余额数字，**都已 gitignore**，别提交。
- 它会读取 Kimi / Trae / Qoder 等客户端存在本机的会话文件来拿余额——**这是你自己的账号、你自己的机器**。工具不做任何提权，换一台没登录这些 App 的机器，它什么都读不到。

## 不做

不开浏览器、不做网页自动化代点、不解系统钥匙串、不碰钱（提现/兑换/绑卡一律不做）、不改各家的安装目录和配置。

## 结构

```
领积分.py        采集与盘查主体（launchd 定时跑它）
Sources/main.swift  菜单栏 App（只读脚本写的状态文件，不排程）
build.sh         打包：编译 → 从母版切 icns → 写 plist → 签名 → 同步 /Applications → 装常驻
tools/冒烟检查.sh  只读自检基线
docs/工作原理.md   各家接口、鉴权怎么拿、状态文件字段、已知问题
```

## 已知边界

各家活动接口和字段会变，某家突然读不到通常是它们改了接口；`docs/工作原理.md` 第五节记着当前已知的问题和排查顺序。欢迎提 issue，但这是个人工具，作者按自己的需要维护。
